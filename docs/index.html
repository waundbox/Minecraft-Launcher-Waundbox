Что умеет Waundbox

Всё, что обычно приходится собирать из трёх программ и пары папок, здесь лежит рядом.

Профили, у каждого свой мир

У профиля своя версия игры, своя папка с мирами и модами, свой объём памяти, свои аргументы запуска и свой значок. Можно запустить сразу несколько игр, а вывод каждой смотреть отдельно во вкладке «Логи».

Персонаж в 3D

Твой скин на главной. Крутится мышкой, а позу можно выбрать в настройках.

Моды с Modrinth

Моды, ресурспаки и шейдеры вместе с нужными зависимостями. Версия подбирается под профиль.

Сборки одним файлом

Импорт .mrpack из Modrinth и .zip из CurseForge.

Тема под тебя

Светлая или тёмная, любой цвет по коду #RRGGBB. «Дым» на фоне можно выключить.

Игра, загрузчики и сборки

Вкладка «Профили» → «Новый профиль». Лаунчер скачивает игру, библиотеки и ресурсы, проверяет каждый файл по контрольной сумме, а при обрыве сети пробует снова.

Оборванная установка не ломает игру. Fabric и Quilt записываются только после того, как скачались все файлы, так что «полуготовой» версии не останется.
Нужна Java? Лаунчер сам ищет её в JAVA_HOME, PATH и обычных папках установки. Автоматической загрузки Java пока нет, но путь можно указать вручную.

Как зайти в игру

Выбираешь аккаунт сам или оставляешь «Автоматически»: сначала Microsoft, потом Ely.by, потом локальный режим.

Microsoft

Официальный вход по короткому коду на странице Microsoft. Пароль лаунчеру не передаётся, на диске лежат только токены, зашифрованные средствами Windows. Нужна лицензия Java Edition.

Ely.by

Вход на сервер авторизации Ely.by, скины и сервера работают через authlib-injector. Двухфакторная защита поддерживается.

Локальный режим

Без входа и проверки лицензии, с любым ником. Подойдёт для одиночной игры и проверки сборок. На серверы с лицензией так не зайти.

Галерея скинов лежит во вкладке «Аккаунт → Скины»: PNG 64×64 или 64×32 можно добавить, выбрать для главной или отправить в Microsoft.

Как установить Waundbox

От скачивания до первого запуска игры. Отдельно ставить .NET не нужно.

  1. Скачай лаунчер. Нажми «Скачать»: откроется страница релизов на GitHub. Возьми последний выпуск (сейчас 1.0.0) и скачай из списка файлов «Установщик».
  2. Запусти установщик. Он сам поставит Waundbox и создаст ярлыки на рабочем столе и в меню «Пуск». Дождись конца установки.
  3. Открой Waundbox. Дважды нажми на ярлык. Лаунчер работает только в одном окне: если он уже открыт, найди его значок на панели задач, а не запускай второй раз.
  4. Войди в аккаунт. Открой вкладку «Аккаунт» и выбери способ входа. В Microsoft нужно ввести короткий код на сайте Microsoft, и для этого нужна лицензионная Minecraft: Java Edition. В Ely.by вводишь логин и пароль от сайта. Если лицензии нет, выбери локальный режим: впиши ник, и игра запустится без входа.
  5. Создай профиль. Во вкладке «Профили» нажми «Новый профиль». Выбери, что ставить: чистый Minecraft, Fabric, Quilt, Forge или NeoForge. Потом версию игры, объём памяти и значок. Лаунчер сам скачает игру, а за ходом загрузки можно следить по полосе прогресса. Передумал? Нажми «Отмена».
  6. Проверь Java. Для обычного Minecraft и Fabric лаунчер ищет Java сам. Для Forge и NeoForge она должна быть уже установлена: для Minecraft 1.21 и новее нужна Java 21. Если лаунчер её не нашёл, укажи путь в «Настройках».
  7. Запусти игру. Вернись на «Главную», выбери профиль и нажми «Играть». Первый запуск может быть долгим, пока докачиваются файлы. Если игра закрылась с ошибкой, загляни во вкладку «Логи»: там виден вывод игры.
